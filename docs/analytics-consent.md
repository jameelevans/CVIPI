# CVIPI Analytics and Consent

GA4 stream: CVIPI / https://cvipi.info. Measurement ID: `G-0J5P2BGBMY`.
Enhanced measurement is disabled in Google to prevent duplicate or uncontrolled events.

## Consent and activation

- No Google Analytics script, cookie, or event is sent before acceptance or after decline.
- Equal Accept/Decline choices; preferences are available from the footer. Choices expire after 180 days.
- Withdrawal enables Google's disable flag before deleting accessible GA cookies. Pending events are discarded, not replayed. Browser Global Privacy Control overrides acceptance.
- Local, staging, and signed-in visits use console-only preview (`[CVIPI analytics preview]`). No production GA traffic is generated by those visits.
- Settings > Analytics & Consent controls the ID and production switch. The switch is currently OFF locally. Live sending additionally requires HTTPS, hostname `cvipi.info`, root installation, a production WP environment, and a signed-out visitor.
- Deployment alone does not copy the WordPress option. Configure the measurement ID and enable production only after reviewing the privacy notice and testing consent on the deployed site.
- Advertising storage, Google Signals, and advertising personalization are disabled. No user IDs, form answers, field values, link text, email/phone destinations, query strings, fragments, or search terms are sent.
- Public URL paths identify pages and downloads. Referrers are reduced to origin. Query stripping intentionally excludes UTM/search data. Review public file names and paths to keep personal information out of URLs.
- This is analytics consent, not a universal third-party blocker: reCAPTCHA, requested embedded videos, forms, hosting logs, and email services operate separately. Mailchimp's separate automatic frontend impression counter is disabled; subscription processing is unchanged.
- A privacy notice should describe Google Analytics, recipients, retention, choices and rights as appropriate. Obtain client/privacy review before live activation; the implementation is not a legal-compliance guarantee.

## Events

| Event | Meaning / parameters |
| --- | --- |
| `page_view` | One accepted page view, sanitized URL, generic page title, page_type, referrer origin |
| `page_not_found` | 404 page; requested URL replaced with `/404` |
| `link_click` | Internal/outbound/anchor/email/phone link, link_area; web URLs only |
| `file_download` | File link activation, file_name, file_extension, link_url; includes middle-click |
| `button_click` | Buttons and role=button, action_name and stable button_key (no text or form values) |
| `scroll_depth` | 25/50/75/90 percent, once each per document |
| `form_start` | First focus in contact/story/newsletter form |
| `form_submit_attempt` | Submit event; newsletter email-only Continue excluded |
| `form_error` | Generic validation/submission failure; no error text |
| `form_success` | Server-confirmed contact/story/newsletter response, form_name |
| `filter_results` | Successful resources/events/stories filter response, content_group, search_used boolean |
| `map_interaction` | marker_open, zoom, pan, filter, reset; repeated gestures throttled |
| `video_open` | Embedded-video lightbox trigger activation (not proof of playback) |
| `video_start`, `video_pause`, `video_progress`, `video_complete` | Actual native HTML5 video controls; 25/50/75 progress. Decorative autoplay videos excluded. |

GA's standard session/engagement/device reporting starts only with accepted production tracking.
Download events measure clicks, not completed file transfers. Share button clicks measure intent, not successful social posting. Cross-origin YouTube/Vimeo playback inside their iframe is not instrumented beyond the lightbox-open event. No session replay, keystroke capture, precise location, advertising, or tracking of visitors who decline.

Event parameters are sent immediately when active. Event-scoped custom dimensions are registered for form_name, file_name, file_extension, action_name, button_key, link_area, link_type, page_type, search_used, error_type, percent_scrolled, video_provider, and video_percent. Google does not backfill custom definitions. form_success is a key event, counted once per event with no monetary value. Ordinary clicks are not key events.
